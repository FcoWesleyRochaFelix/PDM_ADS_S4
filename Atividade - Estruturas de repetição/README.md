## Conteúdo

A atividade é composta por 10 questões envolvendo estruturas de repetição e manipulação de dados em Dart.

Os exercícios abordam laços de repetição, listas, divisores, elementos pares, números naturais, jogos, comunicação com Bob, pontuação de palavras e transcrição de DNA para RNA. 
## Como testar

Execute cada arquivo `.dart` individualmente utilizando o Dart:

```bash id="x7d1mc"
dart questa01.dart
```

Substitua `questa01.dart` pelo arquivo da questão que deseja executar.
