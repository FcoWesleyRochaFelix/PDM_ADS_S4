## Conteúdo

A atividade é composta por 8 questões sobre funções em Dart.

Os exercícios abordam criação e utilização de funções, parâmetros, valores padrão, retorno de valores, atribuição de funções a variáveis e resolução de problemas utilizando funções.

Também são trabalhados problemas como Raindrops, cálculo de idade em diferentes planetas e cálculo de pontos de energia com base em múltiplos de valores. 
## Como testar

Execute cada arquivo `.dart` individualmente utilizando o Dart:

```bash
dart questao_01.dart
```

Substitua `questao_01.dart` pelo arquivo da questão que deseja executar.
